# Implementation Plan — openlms (Teknis, Tanpa Kode)

**Versi:** 1.0
**Tanggal:** 6 Agustus 2026
**Status:** Final desain (input: prd01 [v1] §8, prd02 [v2] §8, prd03 [v3] §8; konsisten dengan 02/03/04; urutan eksekusi mengikuti prd04 §10)
**Estimasi:** relatif (S < 2 hari, M 2–5 hari, L 1–2 minggu) untuk tim 1–3 orang.

---

## 1. Ringkasan

Fase 0–2 adalah **jalur MVP wajib** (skema → **auth in-house + RBAC + scope** → LMS inti). **Aplikasi single-school [owner-v4.2]: tanpa tenant, tanpa school_id.** Berdasarkan prd03 [v3] §8 dan prd02 [v2] §8 (dasar roadmap prd04 §10), fondasi teknis G6/G7/G8/G11, migrasi data G9, consent/retensi G12/G13, dan portal orang tua masuk **WAJIB MVP**; tiga item tambahan **sangat direkomendasikan** setelah Fase 2 stabil: absensi QR, ujian online dasar, e-rapor. Sisanya **ditunda** sampai validasi sekolah pilot.
